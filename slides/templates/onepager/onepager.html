One page connects the finding to the evidence

Use this print-sized layout for a brief that needs to stand alone. Replace the examples with measured results and traceable sources.

1Central finding
2Supporting comparisons
3Practical takeaways

The finding leads the page

Write a full sentence that makes a claim. Explain the consequence, then show the evidence that supports it. Use the same units and time window for each comparison.

The evidence stays traceable

Use real captures, measured data and file references. Label representations and illustrative values clearly.

Three checks precede sharing

  • ✓Run the checker at the actual page size.
  • ✓Inspect every exported PNG yourself.
  • ✓Confirm sources and residual risks.
Residual risk: a page can pass automated checks and still tell a weak story. Review its argument and evidence as well as its layout.
A4 pages use a denser typography scale than presentation slides. Keep the body in normal flow so it remains easy to edit.
